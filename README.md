# 🎮 Jogo da Forca

Um jogo clássico da forca desenvolvido em **Java**.  
O objetivo é adivinhar a palavra secreta antes que as tentativas acabem.

---

## 📌 Funcionalidades
- Exibe a palavra oculta com traços (`_`) representando cada letra.
- Substitui os traços pela letra correta quando o jogador acerta.
- Controla o número de tentativas restantes.
- Finaliza o jogo quando a palavra é descoberta ou as tentativas acabam.
